画布 · 对外接口 内部服务 / HTTP / 事件 / 存储；M1 先做前三个加加密存储，起草接口留 501

内部服务 SERVICE

给编排层、记忆、档案调用的窄接口；不直接摸 SQLite。
create(session_id, lanes, day=None) → Canvas
patch(canvas_id, ops, expected_revision) → Canvas
confirm(canvas_id, expected_revision, request_id) → (Canvas, Record)
get(canvas_id) → Canvas
latest_confirmed(session_id | canvas_id) → Canvas | None
snapshot(record_id) → CanvasSnapshot
delete_record(record_id) → Record
latest_confirmed

给上下文注入用；只返回 confirmed 且未删除的版本。

snapshot

给档案日视图、卡片、导出用；只读，不暴露内部存储。

HTTP · 画布 CANVAS

延续现有 /sessions/... 风格；改与确认都要带版本。
POST/sessions/{id}/canvases

新建空白画布（允许全空）。

GET/sessions/{id}/canvases

该会话相关的画布列表。

GET/canvases/{id}

单张画布（含五栏与来源）。

PATCH/canvases/{id}

逐条增/改/删，带 expected_revision；冲突 409。

POST/canvases/{id}/confirm

确认 → 写记录 v+1；幂等键 request_id。

POST/canvases/{id}/draftM2 · 501

一键起草：只填空栏、标 inferred、带出处。

HTTP · 记录与日视图 RECORDS

档案首页只要预览字段；完整画布点进来再拉。
GET/records?month=2026-11

按天分组，每天给预览列表（主题/概要/卡片数）。

GET/days/{day}

那天全部画布预览（一天可多张）。

GET/records/{id}

单条记录：完整快照 + 卡片。

DELETE/records/{id}

只软删记录，返回受影响的 memory_refs。

事件 EVENTS

画布不直接调记忆/档案，只发事件，谁需要谁订。
canvas.draft_completed

M2；带填写了哪几栏、丢了几条无出处。

canvas.confirmed

画布版本 + 记录 id；记忆提议在这里挂。

record.superseded

旧记录被新版本取代；档案刷新用。

record.deleted

失效旧回复、清弱引用。

存储 STORAGE

data/canvases.sqlite3 · 内容列 AES-256-GCM
canvases

canvas_id / owner / 来源会话 / day / status / revision / lanes_json（加密） / confirmed_revision

records

record_id / canvas_id / canvas_revision / version / superseded_by / observed_at /snapshot_json（加密）

明文列：id、owner、day、status、revision、时间
密文列：lanes、note、snapshot、cards、summary
密钥：data/.canvas.key 或 CANVAS_ENC_KEY
缺密钥 → 拒绝启动（不降级为明文）
窄接口

上层只拿对象，不摸 SQLite；画布不认识 session / orchestrator / psychology。

版本先决

改和确认都带 expected_revision；确认再加 request_id 幂等，防网络重试双写。

只加不删

新字段一律可空带默认；已确认版本的语义不改；预留位先 501，不占语义。

可复现

起草记 persona_id / draft_profile / prompt_version / model；出问题能回查是哪次生成的。

原则：确认才生效 · 版本先行 · 留白合法 M1：画布 CRUD + 确认 + 日视图 + 加密 + 敏感提示 M2：/draft 真生成、卡片、记忆提议接线 错误码：not_found / revision_conflict / canvas_empty / draft_needs_replace
