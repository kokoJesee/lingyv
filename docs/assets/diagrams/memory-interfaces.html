三条契约原则

窄接口调用方只看见 propose / confirm / select，不知道有 SQLite、也不知道 L1/L2 怎么分。
只加不删schema 加字段不删字段，未知字段一律忽略；版本号用乐观锁。
默认关闭预留能力全部 feature flag 默认 off，开了才可能被调用。
档案有四个写入口（画布/存档/便签/补记）；自动提取只挂在画布确认 读入口只有一个：编排层每轮 → select 删入口只有一个：设置页 → delete → 依赖失效 预留字段先加、接口先空、开关先关
