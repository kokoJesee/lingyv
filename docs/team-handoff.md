# 团队对接与业务边界

当前是团队比赛的 Agent 运行底座；通用草稿不是正式心理理解画布。
业务状态保持 INITIAL，心理理解、澄清、画布、视角、K/R/N 与专业安全规则待团队确认接入。

按现有建议分工，PM 确认场景、范围和验收；心理研究给字段、策略与正反例；
安全负责人给检查结果、处置、故障回退和审核资源；UX 给操作流程与展示字段；
数据评测给带预期结果的案例、数据用途和评分依据。实际负责人以团队确认为准。

先对齐“用户表达 → 理解草稿 → 纠正与确认 → 下一轮使用修正版”，以及最小安全路径。
每个接口约定负责人、输入输出、有效/错误样例、确认和版本、超时/拒绝/取消、数据用途、联调时间。
案例检索与穿戴按范围后接，没有设备或未授权也能完成文本体验。
原接口草案的字段、过期时间、性能目标、界面和设备要求均不自动成为正式规则。

本工程仅属于团队比赛；个人独立项目不作为需求、技术路线或验收来源。
当前适用于本机单用户开发，真实多人服务还需身份与会话授权，专业规则需相应负责人审核。
