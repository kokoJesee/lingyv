# 前后端协作接缝

更新：2026-11-05。共享比赛工程，所有模拟内容与未审核能力需清楚标注。

| 接缝 | 当前实现 | 后续协作边界 |
|---|---|---|
| 原运行框架、语音与调用调度 | 保留张俊杰上游 Runtime 0.6 的能力，新增心理调用也经过共享调度 | 修改调用入口需同时回归普通聊天、结构化心理调用和 ASR |
| 盛蕾模块 1—4 | 30 指标契约、模拟输入、用途授权、基线与趋势 | 真实设备适配器另接；不得把厂商分数当心理结论 |
| 盛蕾模块 5—7 | 理解版本、确认/纠正、来源失效、支持路线与原子提交 | route/文案仍 unreviewed；专业审核不由工程测试替代 |
| 盛蕾模块 8 | 独立保存选择与 v2 恢复；恢复不恢复设备用途授权 | 明文、本机单用户；身份认证、云端保管另规划 |
| 现有电影感前端 | 原本地四栏演示与单次联网保留，新增持续后端模式 | 后端模式使用理解条目，不把四栏模拟标为模型结果 |
| 心象宇宙 | 一个空间的状态随已确认理解与支持路线变化 | 完整动作白名单/版本契约仍属模块 9；不自动外部执行 |
| CaseForge/独立评测 | 保留上游内部演示与工程回归 | 模块 10 的独立案例与心理效果评测需另完成 |

接口与操作：[持续支持流程](frontend-support-integration.md)、[业务存档](business-archives.md)、[主流程](agent-support-integration.md)。后端所有路由仍是本机单用户演示，不以 session_id 充当生产身份认证。前端统一走 Next 同源代理，不把模型凭据放浏览器。

一次可复现的团队验收应固定代码版本、模拟 seed/as_of、模型模式和提示词版本，记录工程结果、浏览器结果、真实模型结果与专业审核状态四类证据。模拟生成器的隐藏情境不进入模型，也不能充当独立效果评测答案。
