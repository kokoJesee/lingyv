# 语音输入使用说明

更新时间为 2026-11-04，随 Runtime 0.5.0 提供。

## 开始使用

在项目目录安装依赖并启动服务。

~~~powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B -m uvicorn app.main:app --host 127.0.0.1 --port 8000
~~~

打开 http://localhost:8000/voice 。第一次录音时允许麦克风权限。页面采用 AudioWorklet 采集声音，并在浏览器中转换为 16 kHz、16 bit、单声道 PCM WAV。桌面 Chromium 已用虚构音频模拟麦克风联调，实际麦克风与其他浏览器可按下列流程验收。

1. 选择识别方式，点击“开始录音”。每段最多 60 秒，到时自动停止并转写。
2. 点击“停止并转写”，等待文字出现。
3. 检查并编辑文字，再点击“发送给 Agent”。页面在首次发送时创建会话，后续沿用本次会话。
4. 录音或转写时可点击“取消本次录音”。页面丢弃本轮结果，并请求后端取消对应转写。
5. 点击“新会话”后，下一次发送会创建新会话。

页面默认选中“模拟流程”。该模式返回明确标识的预设文字，用于验证录音上传、编辑和聊天连接。发送文字时会调用已配置的聊天模型。

## 配置腾讯云真实识别

先在腾讯云开通语音识别服务，再通过 API 密钥管理获取有相应调用权限的凭据。密钥填在本地 .env，修改后重启服务。按控制台显示的额度与计费规则使用。[官方接入说明](https://cloud.tencent.com/document/product/1093/54362)

~~~dotenv
ASR_PROVIDER=tencent
TENCENT_SECRET_ID=在本地填写SecretId
TENCENT_SECRET_KEY=在本地填写SecretKey
TENCENT_TOKEN=
ASR_ENGINE=16k_zh
~~~

普通 API 密钥的 TENCENT_TOKEN 留空。使用临时凭据时填写配套 Token，并在凭据到期后更新。DeepSeek 的配置继续用于文字聊天，腾讯云配置用于语音识别。

打开语音页面，确认显示“腾讯云识别已配置”，再选中“腾讯云真实识别”。这一选择表示本次录音会发送到腾讯云。配置状态只检查字段是否齐备，真实录音调用才能验证权限、额度和服务可用性。

浏览器麦克风要求安全上下文。开发时使用 localhost，上线页面使用 HTTPS。手机访问电脑的局域网 HTTP 地址通常不能满足这一要求。[浏览器麦克风要求](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

## 转写接口

GET /audio/status 返回识别模式、配置是否齐备、格式和大小限制，不返回凭据。

POST /audio/transcriptions 接收 multipart/form-data。

| 字段 | 类型 | 规则 |
|---|---|---|
| file | 文件 | 必填，完整 PCM WAV，单声道、16 kHz、16 bit，最多 60 秒、2,000,000 字节 |
| request_id | UUID 字符串 | 可选，省略时生成新编号。需要重放与取消时由调用方预先生成 |
| mode | 字符串 | configured 使用已配置的腾讯云识别，demo 显式选择预设文字演示。默认 configured |

示例响应如下，文字为虚构测试内容。

~~~json
{
  "request_id": "22222222-2222-4222-8222-222222222222",
  "text": "你好，这是语音输入功能测试。",
  "provider": "tencent",
  "simulated": false,
  "duration_seconds": 3.2
}
~~~

前端将用户校对后的文字作为 content，发送至现有 POST /sessions/{session_id}/messages。转写成功时会话历史保持原状，点击发送后才按现有聊天流程提交。语音与聊天各用独立请求编号。

DELETE /audio/transcriptions/{request_id} 取消当前编号的转写，返回 204。提前取消会建立短期作废记录，防止尚在上传的同编号请求继续调用识别。取消已完成的转写会清除其缓存结果。浏览器退出时只会尽力发送取消请求，上游调用是否已计费取决于供应商。

Swagger 的 /docs 页面可以上传符合要求的 WAV 文件进行调试。浏览器录音页可直接生成该格式。

## 限制、保留期与失败处理

腾讯云短语音接口支持最长 60 秒，并限制上传体积。应用将 WAV 限为 2 MB，保证 Base64 后仍在供应商文档列出的 3 MB 数据限制内。格式通过 WAV 内容校验。[腾讯云一句话识别接口](https://cloud.tencent.com/document/api/1093/35646)

| 配置/限制 | 默认值 | 行为 |
|---|---|---|
| 音频长度与文件大小 | 60 秒、2 MB | 上传或校验阶段拒绝超限，返回 413 |
| 上传总量和等待 | 音频上限加 16 KiB 表单开销、15 秒 | 流式检查总量，过大返回 413，过慢返回 408 |
| 同时上传/等待的 HTTP 请求 | 4 | 达上限返回 503 |
| ASR_TIMEOUT_SECONDS | 20 | 单次识别超时返回 504 |
| ASR_MAX_CONCURRENT | 2 | 识别任务并发上限，繁忙返回 503 |
| ASR_MAX_REQUESTS | 100 | 短期去重与取消记录上限，满时返回 503 |
| ASR_CACHE_SECONDS | 600 | 完成后在内存保留结果或错误，计时到期主动清理 |

音频在有界内存中处理，上传解析也保持内存模式。任务完成或取消后释放应用内的音频引用。缓存存放音频摘要、模式、请求编号、文字或安全错误数据，不存异常 traceback。腾讯云的数据处理政策由其服务条款约定，本地清理只覆盖本应用。

同编号、同音频和同模式在保留期内共享同一任务或已完成结果。改用同编号提交不同内容返回 409。失败也会重放，主动重新尝试使用新的编号。记录过期或进程重启后，相同编号可以重新执行，因此调用方应只在一次短期重试中复用编号。

当前转写去重记录属于本机单进程。取消通过编号定位任务，与现有开发接口一样适用于本机单用户联调。多人部署时需补充身份与记录归属检查。

错误响应使用 detail.code 和 detail.message。常见代码包括 audio_not_configured、audio_format_invalid、audio_too_large、audio_too_long、audio_timeout、audio_no_speech、audio_cancelled、audio_request_conflict、audio_busy。日志只包含编号、模式、大小、耗时和错误类型。

聊天发送中若响应丢失，页面保留原请求编号，允许“重试同一请求”。这会使用已有聊天去重能力确认结果，避免因网络中断重复调用模型。
