# LoveStone 前端产品与联调说明

> 2026-11-05 更新：保留原电影页面，按服务端配置自动接入，无页面模式切换。已接授权趋势、理解版本确认与业务存档；操作见 [前端支持流程](frontend-support-integration.md)。下文“后端待接契约”及 2026-11-04 验证保留为历史交付记录。

## 产品范围

LoveStone 当前是面向个人的情绪支持 Agent。心象宇宙是互动入口；角色「拾光」用用户亲自确认的理解衔接回应、当前行动和回顾。页面中的情绪、解释和需求来自可修改的草稿，事实栏也只记录用户自述。设备观察、用户自述、已确认记忆与推测各自保留来源，设备趋势不证明心理状态。

| 页面 | 本次可演示内容 | 边界 |
| --- | --- | --- |
| 心象宇宙 | 打开一次支持对话，进入用户可控制的支持流程 | 角色承载支持反馈；没有自主执行或代用户决定的权限 |
| Personal Agent | 原对话表单按服务端配置接入持续支持；可查看本次旅程历史 | 未配置后端时用本地演示；固定脚本和心理路线仍未经专业审核 |
| Mind Canvas | 查看事实、解释、情绪和需要的关系；在对话中编辑并确认当前理解 | 确认只适用于当前理解；不会自动授权新用途或保存 |
| 个人状态 | 原六段页面中切换 30 指标、7/14/30 日；设置与基线折叠呈现 | 导入模拟记录后单独授权；未授权/缺测留空，无真实设备接入 |
| 成长档案 | 原经历卡筛选和展开；另有折叠的本机旅程存档 | 经历卡只存本页内存；v2 存档需另行同意，不构建长期画像 |
| CaseForge | 切换固定合成案例、示范和反例，运行证据、纠正与选择权规则检查 | 内部研发视图；结果仅说明示例是否满足演示规则，不代表模型或心理效果评测成绩 |

### 演示闭环

1. 输入虚构经历，或使用页面的虚构示例。
2. 在对话页四栏中对照输入编辑事实、解释、情绪或需要。后端未提供结构化四栏时，只放用户原话，其余留白；确认与修改绑定后端当前理解版本，可到心象画布逐层回看。
3. 确认当前理解后，从 Keep、Release、Next 选择一种支持方向，再决定是否保存。这三个选项是当前一步的选择，不会执行外部操作。
4. 在成长档案打开经历卡，核对卡片体现的是用户最后确认的内容和选择。修改和保存由程序界面控制，模型不代替用户确认。

选择 Keep 时，拾光围绕用户确认的需要，邀请留下一句话；Release 支持暂时放下、不急着解决；Next 建议一个小而可撤回的下一步。理解和选择绑定到同一草稿版本。在同一页面会话里再发起一次离线对话，拾光会参考最近保存的支持选择，并在新草稿中询问之前确认的需要是否仍然适用。它仍须重新确认，反馈只存在于演示状态中，不训练模型。

### 设计参考与取舍

首页现已按用户后续提供的电影感首屏要求更新：全屏视频、居中的 Instrument Serif 斜体标题、Barlow 正文、液态玻璃胶囊导航和 CTA，以及 Motion 的逐词模糊入场。保持现有 Next.js 运行框架；参考中的太空旅行文案及虚构合作方替换为 LoveStone 文案和实际功能入口。

- 使用用户指定的 CloudFront 视频地址，实际画面为樱花、湖面与蓝天。视频约 10 秒、17.6 MB、无音轨；由浏览器直接请求外部地址，不携带会话正文。网络不可用时显示本地首帧海报。
- 字体本地加载，字体文件和 SIL OFL 许可证在 `frontend/public/fonts/`。海报位于 `frontend/public/images/hero_bg.jpeg`。
- 首页支持暂停/继续背景视频，并在切换标签页、打开角色介绍和离开首页时暂停；手动暂停选择在当前页面的功能切换间保留。系统减少动态效果设置会关闭自动视频与入场移动，用户仍可主动播放。
- 「认识拾光」打开可关闭的角色介绍；首页导航、主要按钮、底部五个旅程词均连接到已有功能。移动端提供可用键盘关闭的折叠导航。

根据用户后续提供的四页视觉任务，内页也改为独立场景：

| 内页 | 视觉与可用交互 |
| --- | --- |
| 拾光对话 | 黑色背景、下移 17% 的光涡影像、Instrument Serif 正体标题、玻璃胶囊输入与圆形发送按钮；输入自动增高，完成回复后定位到可纠正的四栏。场景随确认、Keep/Release/Next 改变，主动保存经历卡。 |
| 心象画布 | 列车窗外风景、大字系统黑体与浅色玻璃层；切换事实/解释/情绪/需要，展示当前草稿及来源，返回对话修改。 |
| 身心状态 | 保留黑底六段布局、原视频与 Instrument Serif/Inter 排版；接入后端时在原图表切换 30 指标、7/14/30 天，卡片内折叠数据设置。无后端配置时保留原三指标样例。 |
| 成长档案 | 保留画面右侧星球的星空视频、左对齐标题、Keep/Release/Next 导航；按已保存卡片筛选、展开当前确认的内容。 |

`WorldMedia` 统一管理静音内联视频、进入视口后加载、离开视口/隐藏标签页暂停、手动暂停与失败海报。对话页按参考实现独立循环：500ms 淡入、剩余 0.55 秒时淡出、结束后 100ms 重新播放；取消旧的动画帧并从当前透明度继续。HLS 优先使用浏览器原生能力，否则按需加载 hls.js。各段单独提供播放控制；离开页面后卸载播放器。

内页使用参考中的确切视频地址；本地海报是对应素材的真实帧（HLS 使用对应 Mux 缩略图）。网络播放依赖外部 CloudFront/Mux；请求不包含对话内容，但服务商可以看到常规网络请求信息。档案的 PPMondwest 使用用户指定的远程字体 URL，没有把许可未确认的字体复制进仓库，加载失败时使用本地衬线字体。其余字体及 OFL 许可随前端提供。未添加参考原文中的订阅、付款、预订、虚构合作方或社交链接。

### 数据与评测边界

- 只用虚构内容，无真实设备读取、登录、账户隔离或生产级保管。设备导入与用途授权独立；本机分析和对话使用分别选择。经历卡、支持选择只在本页内存中；刷新不代表删除后端会话。
- 「本机旅程存档」另经明确勾选保存后端对话、自述、理解和设备记录到明文 SQLite；不保存或恢复前端经历卡。恢复后设备用途清零；清空内存与删除磁盘独立。`key_configured` 仅表示有配置，不验证模型可用性。
- 固定脚本不调用模型；真实模型配置下，每次发送需明确同意，会使用本次文字、会话历史、当前确认理解及另行获准的设备观察。密钥由 Python 持有；Keep/Release/Next 和经历卡仍是页面选择，不代表外部执行。
- CaseForge 应使用用途已获授权的案例、经核对许可的公开案例和受控合成案例；记录来源、权利、审核、家族和集合划分。同源衍生案例不能跨开发集与保留评测集。用户对话和卡片不流入案例知识层。现有 [Python 离线评测](批量评测运行器.md) 衡量运行行为；当前没有独立的心理效果评测结果。
- 当前理解纠正和设备用途已接入后续上下文；独立心理效果评测、真实设备、长期记忆、专业安全策略和多用户认证仍待完成。B2B 数据或评测服务只列入后续路线。

## 现有 API

保留 FastAPI Runtime、语音输入与共享调用调度，持续支持走 Next 同源代理。语音入口与确认流程见 [语音输入说明](voice-input.md)；仅用于本机联调，启动见 [README](../README.md)。

### 按服务端配置接入

1. 按 [持续支持流程](frontend-support-integration.md) 启动本机 FastAPI。无真实模型演示设 `PSYCHOLOGY_ENABLED=true PSYCHOLOGY_DEMO_MODE=true`。
2. 在 `frontend/.env.local` 设 `LOVESTONE_AGENT_API_URL=http://127.0.0.1:8000`，再重启 Next；模型 Key 只放后端，不使用 `NEXT_PUBLIC_` 暴露配置。
3. 页面读取服务端能力后直接接入原对话、画布、身心与档案页。每次发送仍需同意；连接失败显示错误，不自动换成模拟成功。

未配置后端地址时保留本地演示；配置后端但关闭心理流程时，沿用 `/api/agent` 单次普通聊天。心理流程开启后使用 `/api/support/*` 和持续会话；后端配置决定固定脚本或模型调用，页面无手动技术模式。

### FastAPI 入口

| FastAPI 接口 | 输入 | 输出与语义 |
| --- | --- | --- |
| `GET /health` | 无 | `status`、`llm.key_configured`、`runtime` 等配置和运行信息 |
| `POST /sessions` | 无 | `201`，含 `session_id`、`status`、`state`、`revision` 与 `workflow` |
| `POST /sessions/{session_id}/messages` | `{ "content": "虚构经历", "request_id": "UUID" }`；`request_id` 可省略 | `reply` 文本、`session_id`、`request_id`、`run_id`、`state`、`revision`、`workflow`、可空 `context_manifest` |
| `DELETE /sessions/{session_id}/messages` | 无 | 清理本机运行内存里的会话正文、草稿、上下文和回复缓存；不能撤回已提交给模型服务的内容 |
| `POST /sessions/{session_id}/end` | 无 | 结束会话并拒绝后续提交；与清空内容是两项操作 |

同一会话内相同 `request_id` 与内容复用结果（也复用失败）；用户明确重试时使用新 UUID。`409` 表示状态或编号冲突，`413` 表示超出上下文预算；模型错误常见为 `502`、`503` 或 `504`。当前业务状态仍为 `INITIAL`。运行的 `COMPLETED` 只表示该轮文本聊天结束，不表示已完成心理理解。
